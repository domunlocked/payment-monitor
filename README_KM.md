# Payment Monitor

កម្មវិធីនេះដំណើរការលើកុំព្យូទ័រ Windows របស់អ្នក ដើម្បីតាមដានសារទូទាត់ ABA PayWay ថ្មីៗក្នុងក្រុម Telegram មួយដែលបានកំណត់។ កុំព្យូទ័ររក្សាទុកប្រវត្តិពេញលេញក្នុង SQLite។ Cloudflare Tunnel អាចឱ្យគេហទំព័រ GitHub Pages ដែលមានស្រាប់ទាញយកប្រតិបត្តិការថ្មីដោយផ្ទាល់ពីកុំព្យូទ័រ ដោយមិនប្រើ cloud database ឬ account login។

## សុវត្ថិភាព និងឯកជនភាព

- API ក្នុងកុំព្យូទ័រដំណើរការតែលើ `127.0.0.1:8765`។ មិនបើក router port ឬបង្ហាញ Windows API ទៅអ៊ីនធឺណិតទេ។
- API ក្នុងកុំព្យូទ័រនៅតែ bind តែលើ `127.0.0.1:8765`; មិនបើក router port ទេ។
- Tunnel ប្រើ HTTPS និងអនុញ្ញាតឱ្យមើលតែព័ត៌មានប្រតិបត្តិការដែលបានកាត់បន្ថយ ដោយត្រូវការកូនសោដាច់ដោយឡែក `REMOTE_ACCESS_TOKEN`។ កូនសោត្រូវបានបញ្ចូលដោយម្ចាស់លើទូរសព្ទ ហើយមិនដាក់ក្នុង JavaScript សាធារណៈទេ។
- អ្នកណាដែលទទួលបានកូនសោអាចមើលប្រវត្តិទូទាត់ពីចម្ងាយបាន។ API ពីចម្ងាយមិនអាចបញ្ជា Telegram ឬទាញយក CSV បានទេ។
- Telegram session និង SQLite ពេញលេញនៅលើកុំព្យូទ័រប៉ុណ្ណោះ។
- ឈ្មោះអតិថិជន និងលេខប្រតិបត្តិការជាព័ត៌មានឯកជន។ កុំបង្ហោះ `.env`, `payment-monitor.session`, `payment_history.sqlite3`, logs និង backup ទៅ GitHub។
- ការប្រកាសលើទូរសព្ទត្រូវការសំឡេងខ្មែរពិតក្នុង browser ទូរសព្ទ។ បើគ្មាន សារប្រាក់នៅតែបង្ហាញ ប៉ុន្តែមិនប្រើសំឡេងអង់គ្លេសជំនួសទេ។ មិនអាចធានាការប្រកាសពេលបិទ ឬផ្អាក browser បានទេ។

## ការណែនាំ

សូមអាន [SIMPLE_SETUP.md](./SIMPLE_SETUP.md) សម្រាប់ Cloudflare Tunnel, Windows និងការចូលប្រើលើទូរសព្ទ។ សម្រាប់ការប្រើក្នុងកុំព្យូទ័រតែមួយ អាន [SETUP_SIMPLE.md](./SETUP_SIMPLE.md)។

